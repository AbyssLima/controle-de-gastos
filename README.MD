# Controle Financeiro Pessoal

Projeto desenvolvido em Python com o objetivo de praticar lógica de programação e desenvolver habilidades na construção de aplicações.

## Sobre o projeto

O Controle Financeiro Pessoal é uma aplicação de terminal (CLI) que permite cadastrar e gerenciar movimentações financeiras, como receitas e despesas.

O projeto está em desenvolvimento e faz parte do meu portfólio de programação.

## Funcionalidades

- Adicionar movimentações financeiras.
- Listar movimentações cadastradas.
- Editar movimentações existentes.
- Excluir movimentações.
- Consultar resumo financeiro.
- Calcular receitas, despesas e saldo.
- Agrupar despesas por categoria.
- Validar valores e tipos de movimentação.
- Salvar movimentações em arquivos JSON.
- Carregar movimentações automaticamente ao iniciar o programa.

## Tecnologias utilizadas

- Python 3
- JSON
- Git
- GitHub

## Como executar

1. Clone este repositório.
2. Certifique-se de ter o Python instalado.
3. Abra o terminal na pasta do projeto.
4. Execute:

```bash
python controle_de_gastos/main.py
```

O arquivo `movimentacoes.json` será criado automaticamente na primeira gravação. Os dados ficam armazenados localmente e são carregados quando o programa é iniciado novamente.
